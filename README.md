# Simple Interest Calculator

## Description
This project calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal: The original amount of money.
- Rate: The annual interest rate in percentage.
- Time: The time period in years.

## Output
The program displays the calculated simple interest.

## Example
- Principal: 1000
- Rate: 5%
- Time: 2 years
- Simple Interest: 100
